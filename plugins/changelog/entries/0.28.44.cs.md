---
version: 0.28.44
title: Spravovaná prostředí nyní používají odolný strojový runtime
---

Spravované Projekty a trvalé Sites nyní používají jeden dokončený runtime systemd-nspawn. Jejich soubory,
nainstalované balíčky a konfigurace zůstávají na trvalých discích, příprava hostitele je viditelná v Sandboxu
a odstranění čeká, dokud skutečně nezmizí všechny privilegované prostředky.

### Spravovaná prostředí

- Nová prostředí se vytvářejí z ověřených publikovaných kořenových souborových systémů a běží jako stroje
  systemd-nspawn. Odstraněný runtime Podman už není dostupný. Starší prostředí, které mu stále patří, je nutné
  odstranit a vytvořit znovu.
- Kořenový souborový systém přežije zastavení, spuštění, nové vytvoření obálky i změnu prostředků. Snímky a
  obnovení zachovají data prostředí a před spuštěním obnoveného stroje je ověří.
- **Nastavení → Pluginy → Sandbox → Runtime hostitele** ukazuje připravenost hostitele a požadovaných kořenových
  souborových systémů. Správce může pevně daný runtime připravit jednou omezenou akcí.

### Síť

- Prostředí Projektu může používat sdílenou, nebo zcela izolovanou síť. Izolovaná prostředí nemají odchozí
  přístup a nepřijímají žádné mapování příchozích portů.
- Správci mohou ke sdílenému prostředí přidat výslovná příchozí mapování TCP nebo UDP. Hostitel ostatní příchozí
  provoz odmítá a deklarovaná mapování aplikuje přes nativní nastavení stroje.
- DNS používá uplink resolver hostitele přes vazbu pouze pro čtení. Kontrola připravenosti hlásí DNS, firewall
  a předpoklady stroje odděleně, takže neúspěšné spuštění pojmenuje chybějící schopnost hostitele.

### Spolehlivost a úklid

- Odstranění prostředí zachová trvalý kontrolní bod, dokud nezmizí úložiště, nastavení stroje a runtime artefakty.
  Teprve poté uvolní jeho rozsah uid pro pozdější použití.
- Odstranění Site zůstává opakovatelné, dokud není odstraněn publikační socket, záznam gateway, konfigurace nginx
  a certifikát. Dočasně nedostupný Sandbox nebo ovládání gateway se hlásí jako chyba úklidu.
- Vytvoření, obnova a uvolnění publikace se serializují, takže se obnovený forwarder nemůže vrátit po odstranění
  publikace.

### Kompatibilita

- Plugin Sites vyžaduje jádro **0.28.44**. Připravenost a příprava hostitele nyní patří Sandboxu, takže na něj
  stránka nastavení Sites odkazuje místo druhého nastavovacího API.
- Plugin UI API zůstává **16**, API sdílených pomocníků **4** a minimální verze Node.js **22.12.0**.

### Vydání pluginů z registru ve stejném období

- **sites 0.11.3-chetty.1** používá dokončený runtime kontrakt Sandboxu a zachovává trvalý destruktivní úklid.
