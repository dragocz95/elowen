---
version: 0.28.45
title: Vyhľadávanie v nastaveniach a jednoduchšie publikovanie webov
---

Táto verzia uľahčuje orientáciu v Nastaveniach, zobrazuje využitie prostriedkov spravovaných Projektov, opravuje
kontrolu runtime v Sandboxe a odstraňuje aplikačné runtime, ktoré predtým vlastnili jednotlivé Sites.

### Nastavenia

- Nastavenia sa teraz otvárajú ako prehľadávateľný panel nad používanou stránkou. Vyhľadávanie a ovládanie
  klávesnicou zahŕňa vstavané časti aj nastavenia pluginov a zachováva pôvodnú stránku.
- Limity a sieť spravovaného prostredia Projektu sa ukladajú priamo z panela a zobrazujú spoločný stav
  automatického uloženia.

### Spravované Projekty

- Riadky Projektov teraz zobrazujú namerané využitie procesora, pamäte a disku prostredím systemd-nspawn vrátane
  jednoznačných stavov načítania, zastavenia a nedostupnosti.
- **Nastavenia → Pluginy → Sandbox → Runtime hostiteľa** určuje vlastníka prostredia podľa runtime uloženého v jeho
  diskovom zázname. Platný disk systemd-nspawn so starším názvom obrazu Podman už nedostáva chybný pokyn na
  odstránenie, zatiaľ čo chýbajúci alebo nepodporovaný runtime sa naďalej hlási ako historický.

### Pokyny agenta a Editor

- Pokyny pre jadro, platformy, plánované úlohy, režimy CLI a delegovaných agentov teraz používajú kratšie sekcie
  Markdown so zachovaním všetkých runtime zástupných hodnôt, hraníc oprávnení a pravidiel kontinuity.
- Editor 0.4.4 odstraňuje cestu aktívneho súboru z hornej lišty a zobrazuje jej úplnú cestu na hostiteľovi alebo v
  spravovanom prostredí s ikonou úložiska v spodnom stavovom riadku.

### Sites

- Sites teraz zverejňujú nemenné statické releasy alebo odovzdávajú požiadavky aplikácii, ktorá už beží v
  explicitnom spravovanom Projekte. Proxy vlastní iba adresu, TLS a pravidlá prístupu; životný cyklus a logy
  zostávajú pri Projekte.
- Publikácie command a PHP, ovládanie runtime, logy, dohľad nad procesmi a runtime sockety boli odstránené spolu so
  samostatným životným cyklom prostredia Site, snapshotmi a nástrojmi na spúšťanie.
- Historické záznamy command, PHP a environment zostávajú neaktívne a skryté na audit. Sandbox ukončí každý
  overený historický stroj Site bez odstránenia jeho záznamov, snapshotov, úložiska, záloh alebo pridelenia UID.

### Kompatibilita

- Existujúce platné prostredia spravovaných Projektov nevyžadujú migráciu ani nové vytvorenie.
- Sites 0.12.0 vyžaduje core 0.28.45.
- API používateľského rozhrania pluginov zostáva vo verzii 16, API zdieľaných pomocných funkcií vo verzii 4 a
  minimálna verzia Node.js zostáva 22.12.0.
