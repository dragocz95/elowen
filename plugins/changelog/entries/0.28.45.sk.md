version: 0.28.45
title: Správna kontrola runtime spravovaných prostredí
---

Táto opravná verzia spresňuje kontrolu pripravenosti hostiteľa v plugine Sandbox pre spravované Projekty a trvalé
Sites. Existujúce prostredia systemd-nspawn zostávajú platné, aj keď ich diskové záznamy obsahujú historický
názov obrazu Podman.

### Spravované prostredia

- **Nastavenia → Pluginy → Sandbox → Runtime hostiteľa** teraz určuje vlastníka prostredia podľa runtime uloženého
  v jeho diskovom zázname. Rovnaká hodnota vyberá runtime, ktorý prostredie spúšťa a obnovuje.
- Prostredie systemd-nspawn so starším odkazom `localhost/elowen-project-base:*` sa teraz správne hlási ako
  pripravené a už nedostáva chybný pokyn na odstránenie a nové vytvorenie.
- Neodstránené prostredie s chýbajúcim alebo nepodporovaným diskovým runtime sa naďalej hlási ako prostredie
  patriace odstránenému runtime Podman. Záznamy odstránených prostredí sa do kontroly nezapočítavajú.

### Kompatibilita

- Platné prostredia systemd-nspawn nevyžadujú migráciu ani nové vytvorenie.
- API používateľského rozhrania pluginov zostáva vo verzii 16, API zdieľaných pomocných funkcií vo verzii 4 a
  minimálna verzia Node.js zostáva 22.12.0.
