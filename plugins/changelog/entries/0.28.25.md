title: Plugins can put live cards straight into the chat
tags: [Plugins, Chat]

A plugin can now anchor its own **inline artifact** to a tool call in the transcript. The card stays with
the call it belongs to, survives a reload, and the plugin that owns it can update or close it later.

### What changed

- Web chat renders these artifacts lazily, so a long conversation does not pay for cards nobody scrolled to.
- Terminals that speak the Kitty or iTerm2 image protocol show bounded live thumbnails; every other terminal
  keeps the text fallback, so nothing is lost on a plain SSH session.
- A plugin service is now given a bounded shutdown window after the turn drain. A service that owns a browser
  or a child process can release profile locks and processes before the daemon exits, instead of being cut off.

### Compatibility

- The plugin UI contract is API 13 (`elowen-plugin-ui-kit` 0.8.0). It adds artifacts without touching the
  existing page, settings, Account, User, Project, modal or card contracts, so an older bundle is unaffected.
- The minimum supported Node.js version is now **22.12.0**, matching the runtime shipped for registry
  browser plugins.
