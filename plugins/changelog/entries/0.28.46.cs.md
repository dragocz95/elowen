version: 0.28.46
title: Karty Projektů, bezpečnější publikování a nativní worktree
---

Tato verze zpřehledňuje Projekty, sjednocuje Účet a Nastavení do stejného modelu panelů, odstraňuje zastaralou vrstvu pracovních prostorů Sandboxu a posiluje zabezpečení sítě spravovaných Projektů i snímání publikovaných stránek.

### Projekty a navigace

- Projekty se nyní zobrazují jako responzivní karty s větví, týmem, umístěním a naměřeným využitím procesoru, paměti a disku. Karta i detail používají jeden omezený snímek prostředků a při částečném obnovení zachovají poslední úplná data.
- Účet se stejně jako Nastavení otevírá nad aktuální stránkou. Nastavení i Účet mají v navigaci každý jeden řádek a Nastavení na telefonu zachovává stálý pruh sekcí.
- Hodnoty ukazatelů, odkazy na detail Projektu, ovládání kolečkem a dotykové cíle nyní odpovídají skutečnému stavu a rozměrům.

### Práce s repozitáři

- Práce s repozitáři nyní používá nativní Git worktree. Zastaralý výběr pracovních prostorů Sandboxu a související části CLI, webu, pluginů a delegovaných agentů byly odstraněny.
- Agenti běžící na pozadí a navigace ve vnořených delegovaných relacích nyní přežijí obnovení promptu a používají jednu cestu ke správnému přepisu konverzace.

### Spravované Projekty a zabezpečení

- Kořeny úložišť, kontrola připravenosti, obnova publikací a ukončování nyní selžou bezpečně, pokud nelze prokázat vlastnictví nebo dostupnost. Publikační práce se před ukončením dokončí a obnovené prostředí se odblokuje až po bezpečném obnovení transportu.
- Privilegovaný pomocník provádí ověřené operace se stromy přes již otevřené deskriptory a připravuje soubory vlastněné rootem mimo dosah servisního účtu.
- Spravovaná prostředí mají nadále zablokovaná metadata na link-local adresách a služby cloudové platformy. Pokud je vybraným resolverem DNS platformy Azure, povolí se pouze DNS přes TCP a UDP na tuto přesnou adresu; HTTP a ostatní požadavky zůstávají zablokované.

### Sites a Browser

- Nové publikace Sites mají jediný model: adresa přímo přeposílá požadavky do aplikace, která již běží v aktivním spravovaném Projektu. Sites nic nekopíruje, nesestavuje ani nespouští.
- Existující starší souborové publikace se nadále servírují, obnovují a mažou, ale nelze je znovu vytvářet ani publikovat.
- Browser 0.4.0 pořizuje snímky stránek v novém dočasném profilu Chrome přes vynucující proxy připnutou k přesnému publikovanému HTTPS originu. Přesměrování na jiný origin, privátní adresy, alternativy s přímou IP a změna DNS jsou odmítnuty. Timeout i zastavení pluginu drží odpovědnost za úklid, dokud se pozdě spuštěný prohlížeč nezavře.

### Verze pluginů v registru

- **Browser 0.4.0** přidává interní capture control pro Sites s připnutým originem.
- **Sites 0.14.0** používá pouze proxy spravovaného Projektu, přidává snímky stránek a zachovává čtení, rollback a mazání existujících souborových publikací.

### Kompatibilita

- Elowen core má verzi 0.28.46. Plugin UI API zůstává 16, shared-helper API 4 a minimální verze Node.js 22.12.0.
- Browser 0.4.0 vyžaduje core 0.28.46. Sites 0.14.0 vyžaduje core 0.28.45 a používá Browser 0.4.0, pokud jsou snímky stránek dostupné.
