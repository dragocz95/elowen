The largest release of the 0.28 line. The dashboard now opens with a recap written for you, and the whole
application interface has moved onto shared, accessible primitives.

### Your own dashboard

The dashboard opens with recent conversations, yesterday's activity and suggested next steps, plus a
greeting, a standing question and quick actions written in your own language. Recaps are prepared on the
server and cached per account, and generating one never creates a chat session of its own.

Dashboard settings control which sections appear, which model writes the digest, when to regenerate it by
hand, and how many refreshes per day to run (1 to 24). A 30-day usage chart sits alongside them.

### Working with the agent

- **Fast mode** is remembered per account for supported OpenAI, Azure OpenAI and Anthropic routes. A model
  that does not support it keeps your preference without sending an invalid option to the provider.
- Sub-agents and workflows can be **confined to a workspace**. The scope survives recovery and continuation,
  file and terminal tools speak workspace-relative paths, and nested delegated work is awaited before the
  parent reports that it finished.
- Images read by the `Read` tool get an inline preview, and every image in a conversation opens in an in-app
  viewer.
- Conversation titles are regenerated as the conversation develops.

### Interface

The real application UI now uses shadcn-style wrappers over Radix primitives for dialogs, menus, selects,
toasts, checkboxes, sliders, radio groups, avatars and form controls, so keyboard behaviour, focus
restoration and layering come from one shared place. The legacy design system is retired; two Studio skins
ship, `studio-light` by default and `studio-oled` as the dark variant.

Autosave across configuration and account screens was hardened: writes are serialized, pending edits flush on
close, an invalid draft stays editable, and a stale response can no longer overwrite a newer edit. The states
now say which of saving, saved, activation pending, validation failure, transport failure or revision conflict
you are looking at.

The browser terminal and its WebSocket infrastructure were removed. Terminal execution remains available
through the agent's tools and the CLI.

### Fixed

- A turn interrupted by a restart keeps and shows its parked partial output.
- Compaction and prompt caching measure the complete prefill baseline, so cadence resets properly after a
  respawn and ambient context is not repeated.
- Usage reset advances a per-account accounting epoch instead of rewriting historical rows, so pre-reset
  usage stays excluded after compaction and reconnect.
- Command output budgets are counted in UTF-8 bytes over the complete framed result, keeping both the
  beginning and the end and never splitting a multibyte character.
