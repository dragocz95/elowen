---
version: 0.28.44
title: Spravované prostredia teraz používajú odolný strojový runtime
---

Spravované Projekty a trvalé Sites teraz používajú jeden dokončený runtime systemd-nspawn. Ich súbory,
nainštalované balíky a konfigurácia zostávajú na trvalých diskoch, príprava hostiteľa je viditeľná v Sandboxe
a odstránenie čaká, kým naozaj nezmiznú všetky privilegované prostriedky.

### Spravované prostredia

- Nové prostredia sa vytvárajú z overených publikovaných koreňových súborových systémov a bežia ako stroje
  systemd-nspawn. Odstránený runtime Podman už nie je dostupný. Staršie prostredie, ktoré mu stále patrí, je
  potrebné odstrániť a vytvoriť znova.
- Koreňový súborový systém prežije zastavenie, spustenie, nové vytvorenie obálky aj zmenu prostriedkov. Snímky a
  obnovenia zachovajú dáta prostredia a pred spustením obnoveného stroja ich overia.
- **Nastavenia → Pluginy → Sandbox → Runtime hostiteľa** ukazuje pripravenosť hostiteľa a požadovaných koreňových
  súborových systémov. Správca môže pevne daný runtime pripraviť jednou obmedzenou akciou.

### Sieť

- Prostredie Projektu môže používať zdieľanú, alebo úplne izolovanú sieť. Izolované prostredia nemajú odchádzajúci
  prístup a neprijímajú žiadne mapovanie prichádzajúcich portov.
- Správcovia môžu k zdieľanému prostrediu pridať výslovné prichádzajúce mapovania TCP alebo UDP. Hostiteľ ostatnú
  prichádzajúcu prevádzku odmieta a deklarované mapovania použije cez natívne nastavenia stroja.
- DNS používa uplink resolver hostiteľa cez väzbu iba na čítanie. Kontrola pripravenosti hlási DNS, firewall a
  predpoklady stroja oddelene, takže neúspešné spustenie pomenuje chýbajúcu schopnosť hostiteľa.

### Spoľahlivosť a upratovanie

- Odstránenie prostredia zachová trvalý kontrolný bod, kým nezmizne úložisko, nastavenia stroja a runtime
  artefakty. Až potom uvoľní jeho rozsah uid na neskoršie použitie.
- Odstránenie Site zostáva opakovateľné, kým nie je odstránený publikačný socket, záznam gateway, konfigurácia
  nginx a certifikát. Dočasne nedostupný Sandbox alebo ovládanie gateway sa hlási ako chyba upratovania.
- Vytvorenie, obnova a uvoľnenie publikácie sa serializujú, takže sa obnovený forwarder nemôže vrátiť po
  odstránení publikácie.

### Kompatibilita

- Plugin Sites vyžaduje jadro **0.28.44**. Pripravenosť a príprava hostiteľa teraz patria Sandboxu, takže naň
  stránka nastavenia Sites odkazuje namiesto druhého nastavovacieho API.
- Plugin UI API zostáva **16**, API zdieľaných pomocníkov **4** a minimálna verzia Node.js **22.12.0**.

### Vydania pluginov z registra v rovnakom období

- **sites 0.11.3-chetty.1** používa dokončený runtime kontrakt Sandboxu a zachováva trvalé deštruktívne
  upratovanie.
