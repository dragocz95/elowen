version: 0.28.45
title: Správná kontrola runtime spravovaných prostředí
---

Tato opravná verze zpřesňuje kontrolu připravenosti hostitele v pluginu Sandbox pro spravované Projekty a trvalé
Sites. Existující prostředí systemd-nspawn zůstávají platná, i když jejich diskové záznamy obsahují historický
název obrazu Podman.

### Spravovaná prostředí

- **Nastavení → Pluginy → Sandbox → Runtime hostitele** nyní určuje vlastníka prostředí podle runtime uloženého v
  jeho diskovém záznamu. Stejná hodnota vybírá runtime, který prostředí spouští a obnovuje.
- Prostředí systemd-nspawn se starším odkazem `localhost/elowen-project-base:*` se nyní správně hlásí jako
  připravené a již nedostává chybný pokyn k odstranění a novému vytvoření.
- Neodstraněné prostředí s chybějícím nebo nepodporovaným diskovým runtime se nadále hlásí jako prostředí patřící
  odstraněnému runtime Podman. Záznamy odstraněných prostředí se do kontroly nezapočítávají.

### Kompatibilita

- Platná prostředí systemd-nspawn nevyžadují migraci ani nové vytvoření.
- API uživatelského rozhraní pluginů zůstává ve verzi 16, API sdílených pomocných funkcí ve verzi 4 a minimální
  verze Node.js zůstává 22.12.0.
