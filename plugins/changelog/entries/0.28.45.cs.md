---
version: 0.28.45
title: Vyhledávání v nastavení a jednodušší publikování webů
---

Tato verze usnadňuje orientaci v Nastavení, zobrazuje využití prostředků spravovaných Projektů, opravuje kontrolu
runtime v Sandboxu a odstraňuje samostatné trvalé prostředí, které dříve vlastnil každý Site.

### Nastavení

- Nastavení se nyní otevírá jako prohledávatelný panel nad používanou stránkou. Vyhledávání a ovládání klávesnicí
  zahrnuje vestavěné části i nastavení pluginů a zachovává původní stránku.
- Limity a síť spravovaného prostředí Projektu se ukládají přímo z panelu a zobrazují společný stav automatického
  uložení.

### Spravované Projekty

- Řádky Projektů nyní zobrazují naměřené využití procesoru, paměti a disku prostředím systemd-nspawn, včetně
  jednoznačných stavů načítání, zastavení a nedostupnosti.
- **Nastavení → Pluginy → Sandbox → Runtime hostitele** určuje vlastníka prostředí podle runtime uloženého v jeho
  diskovém záznamu. Platný disk systemd-nspawn se starším názvem obrazu Podman již nedostává chybný pokyn k
  odstranění, zatímco chybějící nebo nepodporovaný runtime se nadále hlásí jako historický.

### Sites

- Proxy publikace zůstávají tenkou vrstvou pro adresu, TLS a přístup nad aplikací spuštěnou v explicitním
  spravovaném Projektu. Neměnné statické releasy zůstávají dostupné.
- Samostatný životní cyklus prostředí Site, jeho ovládání, snapshoty a nástroje pro spouštění byly odstraněny.
  Historické záznamy a zálohy zůstávají uložené jako neaktivní auditní data a ověřený historický stroj se ukončí
  bez jejich odstranění.
- Publikace command a PHP zůstávají kvůli kompatibilitě podporované a budou řešeny samostatně v pozdější verzi.

### Kompatibilita

- Existující platná prostředí spravovaných Projektů nevyžadují migraci ani nové vytvoření.
- Sites 0.12.0 vyžaduje core 0.28.45.
- API uživatelského rozhraní pluginů zůstává ve verzi 16, API sdílených pomocných funkcí ve verzi 4 a minimální
  verze Node.js zůstává 22.12.0.
