version: 0.28.25
title: Pluginy mohou vkládat živé karty přímo do chatu
---

Plugin nyní může ukotvit vlastní **inline artefakt** k volání nástroje v přepisu. Karta zůstává u volání,
ke kterému patří, přežije obnovení stránky a plugin, který ji vlastní, ji může později aktualizovat nebo
zavřít.

### Co se změnilo

- Webový chat vykresluje tyto artefakty líně, takže dlouhá konverzace neplatí za karty, ke kterým nikdo
  nedoscrolloval.
- Terminály, které umí obrazový protokol Kitty nebo iTerm2, zobrazují ohraničené živé náhledy; všechny
  ostatní terminály zachovávají textovou náhradu, takže na běžné SSH relaci se nic neztratí.
- Služba pluginu nyní dostane po vyprázdnění tahů ohraničené okno pro ukončení. Služba, která vlastní
  prohlížeč nebo podřízený proces, může uvolnit zámky profilu a procesy dříve, než démon skončí, místo aby
  byla odříznuta.

### Kompatibilita

- Kontrakt UI pluginů je API 13 (`elowen-plugin-ui-kit` 0.8.0). Přidává artefakty, aniž by se dotkl
  stávajících kontraktů stránky, nastavení, účtu, uživatele, projektu, modálního okna nebo karty, takže
  starší balíček není ovlivněn.
- Minimální podporovaná verze Node.js je nyní **22.12.0**, shodně s runtimem dodávaným pro prohlížečové
  pluginy z registru.
